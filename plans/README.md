## Direction findings (options for the maintainer, not ranked against bugs)

1. **Expose real-time updates** — the PRD (`.ai/PRD.md`) requires Supabase
   Realtime push; the plumbing is half-built and dormant:
   `supabaseService.subscribeToLocationProofs()` exists
   (`supabase.service.ts:412-432`) with zero callers, and the migration
   already creates the Realtime publication (`001_initial_schema.sql:48-50`).
   Cheapest credible delivery is documenting the direct Supabase Realtime
   client pattern; a GraphQL subscription is the heavier alternative and adds
   a socket lifecycle + auth surface. Effort M (coarse).
2. **Full-geometry (GeoJSON) storage** — README promises GeoJSON support
   "planned"; ingestion already parses LineString/Polygon/Multi\* shapes but
   throws away everything except the first coordinate
   (`eas.service.ts:349-435`), and the DB column is `GEOMETRY(Geometry,4326)`
   — ready for full shapes. Delivering this makes the OGC surface genuinely
   useful to GIS consumers, the project's stated audience. Effort L (coarse);
   needs a decision on migrating existing point-only rows. Builds on plan 004.
3. **Publish the promised auth/rate-limit story** — `docs/authentication.md`
   promises API keys/JWT/rate limits; the PRD requires input hardening; none
   is implemented. After plan 001's minimal secret guard, the remaining
   decision is product-level: whether the public API stays fully open (then
   delete the promises) or gets keys + limits (then implement; pairs with
   findings 12 and 14). Effort M (coarse), mechanism choice is the real work.

## Findings considered and rejected

- **Wide-open CORS (`app.use(cors())`)**: acceptable by design for a public,
  credential-less read API; revisit only if cookies/auth are added.
- **GraphQL introspection enabled**: deliberate per the code comment
  (`server.ts:21` "Enable introspection for tools like Apollo Explorer") —
  folded into finding 12 as a hardening option, not a standalone defect.
- **`${revoked}` string interpolation in `db.service.ts:234`**: TypeScript
  `boolean`, not request-derived — no injection.
- **Committed secrets in `.env.example` / docker-compose**: placeholders
  only; nothing to rotate there.
- **Express 4 → 5 migration**: Express 4 is maintained; migration cost
  exceeds present benefit. Revisit on EOL signals.
- **README/dev-port mismatch** (`index.ts:14` defaults to 3001, docs say
  3000): real but trivial onboarding friction; fold into any future docs pass.
- **`x25bd`-style typo hunting in docs prose**: not attempted; only
  functionally wrong docs were flagged (finding 21).
